# Visual resources — rights pending

On 2026-10-16 the maintainer requested that the existing visual resources be included while awaiting NCSOFT's response. `metadata/included-resources.json` identifies each included file and its SHA-256. These files are **not covered by the project's GPL-3.0-only grant**.

Skill icons and pet portraits originate from AION 2 and are attributed to NCSOFT and its licensors. The other included files belong to the application's existing visual kit; their individual authorship and derivative-work status have not all been established. The maintainer's instruction to include the files is not permission from the third-party rights holders.

No authorization for public repository, fork or installer redistribution has yet been demonstrated. Attribution does not itself grant a license. No downstream redistribution permission is granted here for these assets. Any later permission must be reviewed for its exact scope; if the rights cannot be resolved, remove or replace the affected resources. Removing them later cannot recall copies already obtained from a public repository.

Consequently, the repository contains GPL-licensed project code alongside assets with unresolved rights. It must not be represented as an entirely cleared open-source distribution or as meeting SignPath's eligibility requirements.

The game-data catalogs, unrelated binaries and excluded source metadata remain listed in `metadata/excluded-resources.json`. Images alone do not restore the catalog-based mapping of skill and pet identifiers. No complete installer has been produced from this preparation.
