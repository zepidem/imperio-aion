# Império AION 0.8.91 — candidato local

Os integrantes com identificação pendente aparecem como **Sincronizando**, com
um indicador dourado animado na HUD e na tabela do painel. O jogador local
continua como **Você**. Cada nome confirmado substitui apenas o seu marcador.

Os nomes reais e os identificadores permanecem internos. A alteração não muda
a captura, o reconhecimento do grupo, o cálculo ou a separação do dano. As
linhas e a seleção das habilidades usam o ator já fornecido pelo coletor para
continuarem ligadas ao mesmo personagem quando seu nome chega.

O pequeno indicador de sincronização permanece animado mesmo quando as
animações decorativas do Windows estão desativadas. Nenhuma configuração do
Windows é alterada. O indicador para quando a tabela não está visível ou não
há nomes pendentes. Recursos e dados
mantêm o armazenamento da versão anterior.

Esta versão apresenta o estado de identificação; ela não acelera os pacotes do
jogo nem confirma uma causa de rede pessoal para o atraso. Validação local com
dados já existentes. Não solicita novas gravações ou testes no jogo.
Não publicada no site ou no canal de produção. Sem Authenticode.
