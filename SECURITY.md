# Security reports

Report suspected vulnerabilities privately to **support@imperiobdo.com**, the support address already declared by the application. Include the affected version, a concise description and a minimal reproduction using synthetic data where possible. Do not put exploitable details or player data in a public issue.

Do not send passwords, authentication codes, signing keys, full packet captures or unredacted diagnostic archives. Ask before sharing sensitive material. No response deadline or bug-bounty program is promised.

This repository is a source preparation, not a supported installable release. Review [docs/BUILD.md](docs/BUILD.md) before building. No SignPath signing integration is active. Integrity signatures used by the updater are separate from Windows Authenticode signatures.
